# Data boundary

This public repository distributes no research data.

The software accepts user-supplied local text files. Source identities, acquisition details, private checksums, working transformations, and research outputs remain outside the public repository.

Do not add corpora, transcriptions, scans, archives, notebooks, result tables, or source inventories to Git. The repository's MIT License does not apply to user inputs.

See [`../PUBLIC_RELEASE_POLICY.md`](../PUBLIC_RELEASE_POLICY.md).
